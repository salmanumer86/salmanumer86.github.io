Here's how recruiters actually use LinkedIn: we search for a stack and a location, we get a list of headlines and photos, and we open maybe one in ten. If you want to be the one in ten, this is what to change.

## 1. Your headline is the whole pitch

The default is your current job title. That's wasted space. Use the 220 characters:

> Frontend Engineer · React, Next.js, TypeScript · Building fintech UIs at Acme · Open to remote roles

Stack first, so the search matches. Context second, so I know what kind of product you've worked on. Availability last, so I know whether to bother.

## 2. Set "Open to Work" — but only recruiters need to see it

The green photo frame makes some hiring managers nervous. The setting has an option to show it *only to recruiters*. Use that one.

## 3. The About section is for the follow-up question

Keep it to five or six lines and make it specific:

- What you build (product type, stack)
- One thing you're proud of, with a number if you have one
- What you're looking for next

If I can form one follow-up question from your About section, you've done it right.

## 4. Fill the Experience section like a CV, not a job description

"Responsible for developing frontend features" is the job description. "Rebuilt the dashboard in Next.js; cut page load from 4s to 1.2s" is your experience. Same rule as [your résumé](/advice/developer-resume-that-clears-screening/): what you built, what it was built with, what changed.

## 5. Pin one link in Featured

A deployed project, a GitHub repo with a good README, or a talk. One is enough. Three is noise.

## What doesn't help

- Posting motivational quotes
- Collecting 50 endorsements for "Teamwork"
- Connecting with every recruiter who appears in your feed. Connect with the ones who work in your stack and city.
